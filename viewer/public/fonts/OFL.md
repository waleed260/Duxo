# Bundled typefaces

All three faces are licensed under the SIL Open Font License 1.1, which
permits bundling and redistribution with this repository.

| File | Family | Designer / Foundry | Upstream |
|---|---|---|---|
| `bricolage-grotesque-var.woff2` | Bricolage Grotesque | Mathieu Triay | https://github.com/ateliertriay/bricolage |
| `manrope-var.woff2` | Manrope | Mikhail Sharanda | https://github.com/sharanda/manrope |
| `jetbrains-mono-var.woff2` | JetBrains Mono | JetBrains | https://github.com/JetBrains/JetBrainsMono |

Each file is the **latin subset** of the upstream variable font, as served by
Google Fonts. They carry their full weight axis (and, for Bricolage, optical
size and width), so every weight the design uses comes from one request.
